Softech 1.1.0 — release verification, 2026-11-12

Shared behavior
- Desktop manager and administrator load the same application and pricing API.
  Permissions determine visibility/actions; there is no second administrator tariff engine.
- Manager mobile settings write through the authenticated club server. Dynamic rule
  edits, full-day intervals, per-room prices and permission revocation were exercised.
- Desktop and mobile reports use the local financial ledger. Super Admin overview,
  inspector and analytics now consume the same synchronized daily reports.
- Cash receipts (cash/card, including balance deposits) are separate from game/bar
  sales (including money spent from balances). Pending bar debt is not paid revenue.

Corrected during this audit
- Missing mobile dynamic-tariff edit permission and UI action; obsolete mobile packages.
- Cashier customer search using an obsolete table instead of actual kiosk accounts.
- Single/group member starts trusting stale browser prices instead of interval quotes.
- Cashier balance-session refunds using an average instead of agreed minute prices.
- Super Admin counting deposits as games, estimating refunds and subtracting twice.
- Paid bar report rows resolving a PC by database ID instead of its club/PC number.
- Shared cloud analytics and daily snapshot handling, including historical refunds.
- Duplicate desktop page headings from the preceding change are included.

Operational limits
- Cloud reports reflect their last successful synchronization (normally about 30 s),
  not live offline activity. Old records are refreshed in the background.
- Cloud source deployment and Server/Client release are both required for the complete
  change. Publishing only the Windows archives cannot update the hosted web panels.
- Tests cover isolated Windows processes and databases. They do not prove every
  customer's firewall, router, disk or Windows logon configuration works.
- Backups remain local, as requested; a failed physical disk requires a separate copy.
