SOFTECH: SERVER, CLIENT VA AKTIVATSIYA TEKSHIRUVI
Sana: 2026-11-05. Mahalliy reliz: 1.0.18.

TOPILGAN VA TUZATILGAN XATOLAR
1. Birinchi ishga tushishda internet bo'lmasa, aktivatsiya so'rovi muvaffaqiyatsiz
   tugab, keyinchalik faqat holat tekshirilardi. Ro'yxatdan o'tmagan yangi
   o'rnatish endi aloqa tiklangach so'rovni qayta yuboradi (kamida 60 soniya
   oralig'ida). PENDING so'rov qayta yuborilmaydi; ban yoki o'chirilgan klub
   qaytadan ro'yxatdan o'tmaydi. Parallel so'rovlar birlashtiriladi.
2. Aktivatsiyada eski 1.0.1 versiyasi yuborilardi. Endi o'rnatilgan paketning
   haqiqiy versiyasi yuboriladi. Bulut HTML/matn qaytarsa, JSON parser xatosi
   o'rniga HTTP statusi bilan tushunarli xabar beriladi.
3. Client setupda oldindan yozilgan begona IP manzili olib tashlandi.
   Foydalanuvchi ws://SERVER_IP:5000/ws manzilini kiritadi; noto'g'ri manzil
   fayllarni almashtirishdan oldin rad etiladi.
4. Client qayta o'rnatilganda yangi server manzili va stol nomi e'tiborga
   olinmasdi. Endi kiritilgan qiymatlar qo'llanadi, boshqa sozlamalar saqlanadi.
5. Server ochuvchisi 5000-portdagi istalgan HTTP 200 javobini Softech deb
   qabul qilishi yoki shu portdagi boshqa jarayonni o'chirishi mumkin edi.
   Endi health javobidagi app/status tekshiriladi. Begona yoki javob bermayotgan
   jarayon portni band qilsa, tushunarli xabar chiqadi; u majburan o'chirilmaydi.

HALI TO'LIQ TASDIQLANMAGAN JOYLAR
- Haqiqiy Telegram tasdiqlash -> klubda aktivatsiya -> xodim akkaunti bilan
  kirish zanjiri jonli klubda sinovdan o'tkazilishi kerak. Testlar tashqi
  Telegram javoblarini nazorat qilinadigan fixture orqali tekshiradi.
- Windows installer GUI, WebView2, firewall, kiosk/watchdog, haqiqiy o'yin
  bandligi, shutdown/reboot va BIOS/NIC Wake-on-LAN alohida client talab qiladi.
- HWID kodi wmic bo'lmagan holatda CIM urinishiga o'tmasdan fallback olishi
  mumkin; MAC/tarmoq adapterlari o'zgarishi ham HWIDga ta'sir qiladi.
  Bu reliz HWID algoritmini o'zgartirmaydi: aks holda mavjud litsenziyalar
  mos kelmay qolishi mumkin. Barqaror yangi HWID uchun migratsiya kerak.
- Litsenziya HMAC kaliti klub dasturiga ham kerak va kodda standart kalit
  mavjud. Bu nusxa ko'chirishga qarshi kuchli kriptografik kafolat bermaydi.
  Alohida xavfsizlik ishlari uchun markaziy private key va klubdagi public key
  bilan imzo tekshirishga o'tish, mavjud litsenziyalarni migratsiya qilish kerak.

PILOT KLUBDA TEKSHIRISH
1. Server/client bir LANda bo'lsin. Setupga serverning haqiqiy IP manzilini
   kiriting; Windows firewall klub tarmog'idan TCP 5000 ulanishiga ruxsat bersin.
2. Aktivatsiya so'rovi kelishi, Telegram tasdiqlash va server holati ACTIVE
   bo'lishini tekshiring. Web super admin orqali alohida staff akkauntlarini bering.
3. Seans ochish/yopish, mijoz balansi, bar savdosi, qaytim va kunlik hisobotni
   haqiqiy kichik summalar yoki alohida test bazasida solishtiring.
4. Telefon orqali ban bering, server/client bloklanishini va restartdan keyin
   ban saqlanishini tekshiring. Internet uzilishi va qaytishini ham sinang.
5. O'yin ochiq paytda update kutishi, bo'sh clientda 10 soniya harakatsizlik,
   serverda 10 soniya harakatsizlik, qayta ulanish, power va WOLni tekshiring.
