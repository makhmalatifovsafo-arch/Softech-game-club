- Quvvat: Wake-on-LAN, o'chirish, qayta yoqish, ekran qulfi.
  Faol seansda katta ogohlantirish: Seansni yopish / Seansni yopmayman.
  Ikkinchi tanlovda seans saqlanadi, vaqt yurishda davom etadi.
  Seans ochilganda ulanmagan kompyuterga avtomatik Wake-on-LAN yuboriladi.
  MAC manzili hamda BIOS/tarmoq kartasida Wake-on-LAN sozlangan bo'lishi kerak.
  Administratorga menejer serverdagi Sozlamalar > Xodimlar bo'limida
  "Kompyuter quvvati (server va mobil)" huquqini beradi/olib tashlaydi.
- Kassa: smena, boshlang'ich naqd, naqd/karta tushumi, kutilayotgan naqd,
  smena ochish/yopish. Jismoniy naqd pulni sanash hali kassirning vazifasi.
- Hisobot: sana oralig'i, naqd/karta manbalari, seans va bar,
  balans to'ldirish va balansdan sarflarni alohida bo'limlar, qarz/qaytim,
  tovar nomi, miqdori, narxi, summasi; tanlangan bo'limni CSVga yuklash.
- Bar: mavjud mahsulotlar, qoldiq, naqd/kartaga savdo.
- Android/iPhone asosiy ekraniga qo'shish; mustaqil ilova oynasi.
- Super adminning menejer/administrator oynasida shu klub mobil havolasi bor.

ARXITEKTURA VA TO'G'RILIK
- Telefon -> HTTPS bulut relay -> klub serveridan chiqadigan so'rov.
- Klubning RSA-OAEP kaliti bilan so'rov AES-GCM kaliti o'raladi; so'rov va
  javoblar shifrlanadi. Bulut navbatida ochiq parol, token, kassa/hisobot yo'q.
- Klub agentining RSA shaxsiy kaliti faqat mahalliy netcafe.db da saqlanadi;
  telefon va bulutga public kalit beriladi. Bazani odatdagi kabi himoyalang.
- Telefonda alohida pul hisoblash algoritmi yo'q: mavjud lokal server API
  hisobotlari va amallari ishlatiladi. RBAC, litsenziya va blok holati saqlanadi.
- Seanslar bir martalik request ID bilan yuboriladi. Bir xil so'rov takrori
  yangi savdo/to'lov ochmaydi; server bajarishdan avval receipt saqlaydi.
- Server o'chib qolib natija noma'lum bo'lsa amal avtomatik takrorlanmaydi;
  holatni tekshirish kerak. Telefon ham noaniq qayta urinishda shu ID ni saqlaydi.
- Yangi buyruq 30 soniyadan keyin bajarilmaydi. Oldin boshlangan amal javobini
  kutish uchun qo'shimcha vaqt bor. Uzoq oflayndan so'ng eski shutdown kelmaydi.
- Server faol mobil so'rovlarda har 2 soniya, bekor turganda har 20 soniya
  bulutni tekshiradi. Birinchi ulanish taxminan 20 soniyagacha kutishi mumkin.
- Kompyuterlar ko'rinishi faol ekranda davriy yangilanadi; oxirgi server javobi
  vaqti ko'rsatiladi. Bu uzluksiz WebSocket translyatsiyasi emas.
- Oflaynda sahifa qobig'i ochiladi; buyruqlar yuborilmaydi, eski ma'lumot
  "aloqa uzildi" deb belgilanadi. API javoblari PWA keshiga yozilmaydi.
- Bu oddiy serverless polling ulanishi; katta klub tarmog'ida Vercel/Supabase
  so'rov sarfi va yukini pilotdan keyin o'lchab, ulanishni optimallashtirish kerak.
