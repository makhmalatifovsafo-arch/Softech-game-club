Softech config.json formatini tiklash

1. ZIP ichidagi barcha fayllarni bitta papkaga chiqaring.
2. Softech Server oynasini yoping.
3. Repair-SoftechConfig.cmd faylini ikki marta bosing.
4. TUZATILDI yozuvi chiqsa, Softech Serverni qayta oching.

Ushbu vosita rasmdagi C:\SoftechServer\config.json uchun tayyorlangan.
UTF-8 BOM yoki UTF-16 formatini BOMsiz UTF-8 ga aylantiradi.
Sozlamalarning qiymatlarini almashtirmaydi. Asl config.json yonida .bak
zaxirasi yaratiladi. netcafe.db va litsenziya fayllariga tegmaydi.

JSON tarkibi buzilgan bo'lsa faylni almashtirmaydi va TUZATILMADI deb
ko'rsatadi. Shu holatda yoki server yana ochilmasa, xato oynasini suratga
oling. Config faylining o'zini ochiq chatga yubormang: unda maxfiy
sozlamalar bo'lishi mumkin.
