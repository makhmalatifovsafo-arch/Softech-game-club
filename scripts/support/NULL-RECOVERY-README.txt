Softech sozlamalarini tiklash (99 ta bosh belgi aniqlangan holat)

1. ZIP ichidagi barcha fayllarni bitta papkaga chiqaring.
2. Softech Server oynasini yoping.
3. Restore-SoftechConfig.cmd faylini ikki marta bosing.
4. TIKLANDI chiqsa, Softech Server dasturini qayta oching.
5. TIKLANMADI chiqsa, shu oynani suratga olib yuboring.

Manzil: C:\SoftechServer
Vosita faqat butunlay NUL belgilari bilan buzilgan config.json ni tiklaydi.
Klub raqami mavjud imzolangan litsenziyadan olinadi. Sozlamalar zaxirasi
bo'lsa shu ishlatiladi; aks holda ushbu Softech xizmatining bulut manzili
va standart yangilash kutish vaqti yoziladi.

Buzilgan config.json alohida .bak fayliga saqlanadi.
netcafe.db, savdo yozuvlari, litsenziya va bloklash fayllari ozgartirilmaydi.
Vosita litsenziya muddatini uzaytirmaydi va klub blokini ochmaydi.
