FAQAT 10-KLUB UCHUN

1. ZIP ichidagi barcha fayllarni bitta papkaga chiqaring.
2. Softech Server oynasini yoping.
3. Recover-Club10.cmd faylini ikki marta bosing.
4. TIKLANDI chiqsa, Softech Serverni oching. Internet ishlashi kerak.
5. TOXTATILDI chiqsa yoki server ochilmasa, shu papkadagi
   Softech-Club10-Report.txt faylini yuboring.

Vosita C:\SoftechServer papkasini tekshiradi. Baza sog'lom bo'lsa,
faqat butunlay buzilgan config.json sozlamasini 10-klub uchun tiklaydi.
Asl sozlama faylining nusxasi saqlanadi. Baza va litsenziya almashtirilmaydi.
Litsenziyani server odatdagi bulut tekshiruvi orqali olishi kerak.
Baza nosoz bo'lsa, vosita to'xtaydi va zaxiralar holatini hisobotga yozadi.
Bu vositani boshqa klub uchun ishlatmang.
